# Python-Assignment-3-While-Loop-For-loop-and-Function

## Overview
This project covers fundamental Python concepts through three practical programming exercises. It focuses on loops, control statements, and user-defined functions.

## Topics Covered

### 1. While Loop – Number Guessing Game
- Generates a random number between 1 and 10 using the `random` module.
- Allows the user three valid attempts to guess the number.
- Provides hints such as "Too high" and "Too low".
- Uses `while`, `if`, `elif`, `else`, `break`, and `continue`.

### 2. For Loop – Multiplication Table Generator
- Accepts a number from the user.
- Generates its multiplication table from 1 to 10.
- Uses `for` loop and `range()` function.

### 3. Functions – BMI Calculator
- Accepts weight in kilograms and height in meters.
- Calculates Body Mass Index (BMI).
- Uses a user-defined function with parameters and return-free output.

## Python Concepts Practised
- Variables and Data Types
- User Input (`input()`)
- Type Conversion (`int()`, `float()`)
- Conditional Statements
- While and For Loops
- Loop Control Statements
- Random Number Generation
- User-Defined Functions
- Arithmetic Operations
